# Screensplained: the data behind the videos

**Screensplained** is a YouTube channel about *the stories behind tech*. When a video makes a claim with numbers we calculated ourselves, the code, the results and the sources are here, so you can check them, rerun them or tell us where we got it wrong.

Each video has its own folder:

| # | Video | What's in the folder |
|---|---|---|
| 002 | **[Turkey Designed a Keyboard for Turkish. QWERTY Won Anyway.](https://www.youtube.com/watch?v=VMBXn1zRJk4)** | 26 million letters of Turkish typed on Turkish Q vs Turkish F: resting keys, pinky load, hand alternation, the 49 / 51 hand split; plus every source used in the video. [→ `002-turkish-f-keyboard/`](002-turkish-f-keyboard/) |

## Found a mistake?

[Open an issue](../../issues) with the video number, the time in the video, and what you think is wrong (with a source if you have one). Corrections are noted in the video's folder and, when needed, in the video description or a pinned comment.
